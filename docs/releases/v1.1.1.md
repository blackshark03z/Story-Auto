# Story Auto v1.1.1 — operations patch

Released 2026-09-23 from annotated tag `v1.1.1`. The product acceptance scope
is the same as [v1.1.0](v1.1.0.md): the Owner-accepted complete Flow final
journey and the separate opt-in Dola Create path that produced one ready O1
master. Dola O2/O3 and a Dola-containing final are outside this scope.

## Start and upgrade

Install Python 3.11 and `requirements.txt`. Extract the Windows ZIP and run
`Start Story Auto.cmd`; open `http://127.0.0.1:8765/`. Keep the server window
open while using the app. The launcher checks whether the exact installation
is already running and avoids opening a second server. If another app uses
port 8765, it reports a conflict. For opt-in Dola browser generation, also
install `requirements-dola-browser.txt` and configure a local session using
the [Dola runbook](../DOLA_BROWSER_UI_RUNBOOK_20260923.md).

When upgrading the local v1.1.0 installation, stop its server, copy its
`runtime` folder into the new v1.1.1 installation, then start v1.1.1. The
public ZIP contains source and launcher only; it does not contain runtime,
videos, browser profiles, or credentials.
