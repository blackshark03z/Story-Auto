## Use

Install Python 3.11 and the packages in `requirements.txt`. Extract
the Windows source package, double-click `Start Story Auto.cmd`, and open
`http://127.0.0.1:8765/`. Keep the command window open while working. The
adjacent `runtime` folder stores local projects and settings. The public
package has no projects, videos, browser profiles, or provider credentials.
For the separate opt-in Dola browser path, install
`requirements-dola-browser.txt` and follow the
[Dola session runbook](../DOLA_BROWSER_UI_RUNBOOK_20260923.md); the package
does not transfer an authenticated browser profile.

The accepted Flow project is kept only in the local qualified installation.
On its completed page, click **Open final video** to watch the final in the
browser's media viewer. The embedded player was removed after the Owner
