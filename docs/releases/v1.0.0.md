# Story Auto v1.0.0 Stable

Released 2026-08-14. This release freezes the accepted Story Auto V1 feature
set at baseline commit `cffc3bb0b325b1c5acc35b9c503de2724d478cd7`. The
annotated `v1.0.0` tag is the canonical source-commit identity for the release.
Normal development after this release is bug- and regression-driven; this
release does not claim that generated media or provider integrations are
perfect.

Video 001 and Video 002 are the canonical production regression projects. Their
exact identities, accepted masters, hashes, durations, evidence pointers, and
acceptance commits are recorded in `v1.0.0.json`. Large runtime trees and media
are intentionally not copied into Git.

## Accepted production baseline

- Full independent long-form production is proven in `full_video_ai` mode.
- Google Flow Web is the production visual provider.
- ElevenLabs, Typecast, and explicitly selected Kokoro Local are supported TTS
  providers.
- Gemini reasoning/QC routing, multi-key/project routing, and model fallback are
  accepted production behavior.
- Resume/idempotency, semantic alignment, hook repetition, temporal video QC,
  rendering, publishing metadata, and canonical final-master integrity passed
  the accepted regressions.
- Build OS authority is kernel 1.22, Lifecycle Kit 1.1.2, Continuity 1.1.0, and
  Context Epoch 1.0.1.

## Known stable limitations

- **Flow visible watermark:** Google Flow Web output can contain a visible Flow
  watermark. This is an accepted V1 limitation. Story Auto does not remove,
  mask, cover, or specifically crop it away.
- **Flow browser automation:** Flow depends on browser/UI automation. Google UI
  changes can require bounded adapter maintenance.
- **Flow authentication:** Interactive Google sign-in can occasionally require
  human action. The dedicated Story Auto browser profile must be preserved.
- **Kokoro Local:** The local TTS provider depends on the installed runtime and
  models under `D:\kokoro`.
- **Gemini reasoning/QC:** Gemini API reasoning and QC depend on configured key,
  project, and quota availability. The production multi-key/project router and
  model fallback remain part of normal behavior.
- **AI output stochasticity:** Generated media can fail semantic, anatomical, or
  temporal QC. Production handles this with QC, rejection, diagnosis,
  repair/regeneration, and selection of a validated asset.

The release adds no provider, editor, QC system, upload workflow, deployment
path, or content workflow and makes no accepted production behavior change.
