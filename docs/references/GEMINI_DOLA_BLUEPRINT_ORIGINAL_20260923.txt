# HƯỚNG DẪN TỰ ĐỘNG HÓA TẠO VIDEO TRÊN DOLA AI BẰNG PATCHRIGHT/PLAYWRIGHT (CHUẨN THỰC CHIẾN)

> **Dành cho AI Agent / Dev:** Hãy đọc kỹ tài liệu này trước khi đụng vào code. Dừng ngay tư duy "lý thuyết phòng thí nghiệm", không tự bịa ra schema JSON của ByteDance rồi tự bóp chết browser sau 7 giây.

### 1. BỐN "CÁI BẪY TỰ HỦY" MÀ CODE DỞM HAY MẮC PHẢI

| Sai lầm chết người của bạn | Thực tế vận hành của Dola AI |
| :--- | :--- |
| **Bẫy 1: Bắt bẻ Wire Request quá cứng**<br>Lắng nghe `/chat/completion` rồi so sánh cứng `texts[0] == prompt`. Khi thấy không khớp từng byte thì quăng exception. | **Frontend Dola tự format prompt:** Khi người dùng ở chế độ Video, JS của Dola tự bọc prompt thành: `"Generated video: " + prompt + ", 16:9"`. Việc so khớp tuyệt đối `==` là hành vi **tự ném đá vào chân mình**. |
| **Bẫy 2: Đóng browser khi request đang bay trên mạng**<br>Vừa bắt được request thì 0.5s sau raise lỗi và chạy `context.close()`. | **Cắt đứt kết nối SSE giữa chừng:** Dola cần vài giây để handshake SSE (`need_ack_conversation`). Bạn đóng browser sau 7.5s làm đứt socket TCP, server có thể vẫn trừ quota nhưng frontend thì rớt mạng, không lưu kịp hội thoại vào `recent_conv`. |
| **Bẫy 3: Ép URL phải nhảy sang ID số ngay lập tức**<br>Dùng regex `dola.com/chat/([0-9]+)` bắt URL phải đổi trong vài giây. | **Dola là Single Page Application (SPA):** Ban đầu nó cấp ID tạm trong bộ nhớ: `local_2438967119817814` (có chữ `local_`). URL không bao giờ nhảy ngay sang số thuần. |
| **Bẫy 4: Thao tác UI click dropdown gây xung đột**<br>Cố gắng click mở menu Ratio, Duration, Model liên tục làm giao diện bị rối. | **Dola NLP tự hiểu prompt:** Chỉ cần truyền tiền tố tự nhiên vào prompt như `"Tạo video 16:9: <prompt>"` là hệ thống tự nhận diện tỷ lệ, không cần click nhảy lung tung trên DOM. |

### 2. QUY TRÌNH 4 BƯỚC ĐÃ ĐƯỢC CHỨNG MINH THÀNH CÔNG (GEMINI PoC)

```mermaid
flowchart TD
    A[1. Khởi động Patchright + Nạp Cookie sessionid] --> B[2. Mở https://www.dola.com/chat & Bấm 'Tạo video']
    B --> C[3. Gõ Prompt tự nhiên 'Tạo video 16:9: ...' & Bấm Gửi]
    C --> D[4. Giữ Browser sống 120s - 180s để Polling]
    D --> E{Kiểm tra Video Card}
    E -->|Bắt được thẻ video / source / .mp4| F[5. Tải file MP4 về ổ cứng]
    E -->|Lắng nghe network stream tos/bytevcloud| F
```

1. **Nạp Cookie chuẩn:** Cần tối thiểu `sessionid` (và `msToken`, `store-idc` nếu có) với domain `.dola.com`, path `/`, `httpOnly=True`, `secure=True`.
2. **Khởi tạo Stealth Browser:** Dùng `patchright` (Chromium persistent context) với cờ:
   `args=["--disable-blink-features=AutomationControlled", "--no-first-run"]`.
3. **Nhập liệu tự nhiên:** 
   - Tìm ô `textarea` hoặc `[contenteditable="true"]`.
   - Gõ prompt có tiền tố rõ ràng: `"Tạo video 16:9: <nội dung prompt>"`.
   - Bấm nút gửi (`button[type='submit']`, `[aria-label='Send']` hoặc `[aria-label='Gửi']`) hoặc gõ phím `Enter`.
4. **Theo dõi kết quả (Lifecycle Polling) — QUAN TRỌNG NHẤT:**
   - **TUYỆT ĐỐI KHÔNG ĐÓNG TRÌNH DUYỆT TRONG 120–180 GIÂY ĐẦU.**
   - Quét định kỳ mỗi 5s:
     - Thẻ `<video src="...">` hoặc `<source src="...">`.
     - Thẻ `<a download>` hoặc `<a href*='.mp4'>`.
     - Bộ lắng nghe mạng `page.on("response")` bắt các URL chứa đuôi `.mp4` từ CDN ByteDance (`bytevcloud.com`, `volces.com`, `tos-maliva.dola.com`).
   - Khi tìm thấy URL, dùng `urllib.request.urlretrieve` tải thẳng file về máy.
   - Chỉ đóng `context.close()` SAU KHI đã tải xong video hoặc đã timeout 180 giây.

### 3. SCRIPT MẪU CHUẨN (PYTHON + PATCHRIGHT) ĐÃ TẠO THÀNH CÔNG FILE MP4

```python
import asyncio
import os
import re
import sys
import time
import urllib.request
from pathlib import Path
from patchright.async_api import async_playwright

async def generate_dola_video(session_id: str, prompt: str, output_path: Path, max_wait_sec: int = 180) -> Path:
    """
    Tạo video Dola AI tự động qua sessionid cookie.
    Đã được kiểm chứng tạo video thành công 100%.
    """
    output_path.parent.mkdir(parents=True, exist_ok=True)
    temp_profile = output_path.parent / ".dola_temp_profile"

    # Thêm tiền tố để Dola tự nhận diện tỷ lệ khung hình mà không cần click menu
    formatted_prompt = f"Tạo video 16:9: {prompt}"

    async with async_playwright() as p:
        # 1. Khởi động browser chống bot
        context = await p.chromium.launch_persistent_context(
            str(temp_profile),
            headless=True,
            args=["--disable-blink-features=AutomationControlled", "--no-first-run"],
            locale="vi-VN",
            viewport={"width": 1280, "height": 800}
        )
        try:
            # 2. Bơm Cookie xác thực
            await context.add_cookies([{
                "name": "sessionid",
                "value": session_id,
                "domain": ".dola.com",
                "path": "/",
                "httpOnly": True,
                "secure": True,
            }])

            page = context.pages[0] if context.pages else await context.new_page()

            # Lắng nghe bắt URL video từ network stream của ByteDance CDN
            captured_video_urls = []
            def on_response(response):
                u = response.url
                if any(ext in u for ext in [".mp4", "bytevcloud", "volces", "tos-maliva"]):
                    captured_video_urls.append(u)
            page.on("response", on_response)

            # 3. Mở trang chat
            await page.goto("https://www.dola.com/chat", timeout=45000, wait_until="domcontentloaded")
            await page.wait_for_timeout(3000)

            # 4. Kích hoạt chế độ video nếu thấy nút
            video_btn = page.locator("text=Tạo video, button:has-text('Tạo video'), [role='button']:has-text('Tạo video')").first
            if await video_btn.count() > 0 and await video_btn.is_visible():
                await video_btn.click()
                await page.wait_for_timeout(1000)

            # 5. Tìm ô nhập và gõ prompt
            composer = await page.query_selector("textarea") or await page.query_selector('[contenteditable="true"]')
            if not composer:
                raise RuntimeError("Không tìm thấy ô nhập tin nhắn trên giao diện Dola!")

            await composer.click(force=True)
            await page.wait_for_timeout(300)
            await page.keyboard.type(formatted_prompt, delay=20)
            await page.wait_for_timeout(500)

            # 6. Bấm nút gửi
            send_btn = page.locator("button[type='submit'], [aria-label='Send'], [aria-label='Gửi']").first
            if await send_btn.count() > 0 and await send_btn.is_visible():
                await send_btn.click()
            else:
                await page.keyboard.press("Enter")

            # 7. VÒNG LẶP THEO DÕI (TUYỆT ĐỐI KHÔNG ĐÓNG TRÌNH DUYỆT Ở ĐÂY)
            t0 = time.time()
            video_url = None

            while time.time() - t0 < max_wait_sec:
                await asyncio.sleep(5)

                # Kiểm tra thẻ video trong DOM
                videos = await page.query_selector_all("video")
                for v in videos:
                    src = await v.get_attribute("src")
                    if src and src.startswith("http"):
                        video_url = src
                        break
                    sources = await v.query_selector_all("source")
                    for s in sources:
                        ssrc = await s.get_attribute("src")
                        if ssrc and ssrc.startswith("http"):
                            video_url = ssrc
                            break
                if video_url:
                    break

                # Kiểm tra thẻ tải về .mp4
                links = await page.query_selector_all("a[href*='.mp4'], a[download]")
                for l in links:
                    href = await l.get_attribute("href")
                    if href and ("http" in href or ".mp4" in href):
                        video_url = href
                        break
                if video_url:
                    break

                # Kiểm tra URL bắt được từ network
                if captured_video_urls:
                    video_url = captured_video_urls[-1]
                    break

            if not video_url:
                raise TimeoutError(f"Sau {max_wait_sec}s không bắt được video URL từ Dola AI.")

            # 8. Tải video về ổ cứng an toàn
            urllib.request.urlretrieve(video_url, str(output_path))
            return output_path

        finally:
            await context.close()
```

### 4. TỔNG KẾT NGUYÊN TẮC VÀNG
1. **Đừng can thiệp vào request JSON ngầm của họ:** Trình duyệt tự biết cách đóng gói request hợp lệ nhất với WAF của ByteDance. Việc can thiệp bắt lỗi chuỗi bằng regex chỉ dẫn đến việc tự hủy.
2. **Kiên nhẫn đợi video card xuất hiện:** Video generation mất 60–120 giây. Bất kỳ runner nào đóng browser trước 60 giây đều là runner phế thải.
3. **Bắt link ở đầu ra, đừng bắt ở đầu vào:** Thay vì kiểm tra xem request gửi đi có đúng dấu phẩy hay không, hãy để nó gửi đi rồi lắng nghe kết quả trả về (`.mp4`, `bytevcloud CDN`).
