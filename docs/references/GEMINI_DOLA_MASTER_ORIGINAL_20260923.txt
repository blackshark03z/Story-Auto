   - **Bản video từ link này 100% KHÔNG CÓ CHỮ `Dola AI`!**

### ĐOẠN CODE BÓC TÁCH LINK KHÔNG LOGO CỦA DỰ ÁN

Trong [tools/dola-render-gateway/video_worker.py](file:///D:/Video/AutoVideoPipeline/tools/dola-render-gateway/video_worker.py#L91-L115), hàm này đã được viết sẵn:

```python
import base64
import json


def extract_unwatermarked_url(video_model_str: str, fallback_url: str) -> str:
  """Giải mã Base64 trường main_url để lấy URL video sạch KHÔNG WATERMARK."""
  try:
    vm = json.loads(video_model_str or "{}")
    video_list = vm.get("video_list") or {}
    candidates = []
    for v in video_list.values():
      if not isinstance(v, dict):
        continue
      main_url = v.get("main_url") or ""
      if not main_url:
        continue
      # Giải mã Base64
      decoded = base64.b64decode(main_url).decode("utf-8", "ignore")
      if decoded.startswith("http"):
        bitrate = int(v.get("bitrate") or v.get("real_bitrate") or 0)
        candidates.append((bitrate, decoded))

    if candidates:
      # Lấy bản có bitrate cao nhất
      candidates.sort(key=lambda x: x[0], reverse=True)
      return candidates[0][1]
  except Exception:
    pass
  return fallback_url
```
